# AutoSmokeGuard — backend dependencies
#
# What this file is
# -----------------
# The *direct* dependencies of the backend, grouped by the job they do, each
# pinned to the exact version the project is developed and tested against on
# Python 3.14.  Transitive packages are deliberately left unpinned so pip can
# resolve them: pinning the full closure here would turn every upstream
# security patch into a merge conflict.  If you need the fully-locked set for
# a reproducible image, `pip freeze` in a clean venv built from this file.
#
# The groups are:
#   web      Django, DRF and the middleware/schema layer around them
#   ml       the vision stack the analysis pipeline runs on
#   pdf      report rendering
#   db       the PostgreSQL driver (SQLite needs nothing — stdlib)
#   tooling  the test runner
#
# This is the *complete* runtime set: a clean `pip install -r requirements.txt`
# gives you an environment that can serve the API, run the ML pipeline and
# render reports.  `requirements-prod.txt` layers the production server (WSGI
# server, process manager) on top of this file; it is maintained alongside the
# Dockerfile and should be installed *in addition to*, never instead of, this
# one.
#
# Install:  pip install -r requirements.txt

# --- database --------------------------------------------------------------
# SQLite (the zero-configuration default) needs no driver.  Setting
# DATABASE_URL to a postgres:// URL switches config/settings.py over to
# django.db.backends.postgresql, which imports psycopg 3 — without this line
# that documented path fails at runtime with ImproperlyConfigured.  The
# [binary] extra ships prebuilt libpq wheels, so no local PostgreSQL client
# libraries or build toolchain are required.
psycopg[binary]==3.3.6
